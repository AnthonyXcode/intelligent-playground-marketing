# 學校資料 `schools.csv`

全港幼稚園（包括幼稚園暨幼兒中心）、小學、中學及特殊學校，一校一行。欄位見 `emails/SPEC.md`。只用公開的官方資料。

## 資料來源（2026-11-19 擷取）

| 標籤 | 來源 |
|---|---|
| `EDB` | 教育局「學校位置及資料」JSON（SCH_LOC_EDB.json）：校名、地址、分區、電話、網址、學校編號（沒有電郵欄位） |
| `PSP2026` | 家校會《小學概覽2026》chsc.hk/psp2026：電郵、校長 |
| `SSP2025` | 家校會《中學概覽2025/26》chsc.hk/ssp2025（2026版尚未公開）：電郵、校長 |
| `SPSP` | 家校會《特殊學校概覽》chsc.hk/spsp（只有35間）：電郵、校長 |
| `KGP2026` | 《幼稚園及幼稚園暨幼兒中心概覽2026/27》kgp2026.kindergartenprofile.com：電郵、校長 |
| `WEB` | 概覽沒有電郵時，抓取學校網站首頁（或一個「聯絡」頁），只接受與學校網域相同的電郵或免費郵箱 |

## 處理規則

- `id`：`KG-`＋10位學校編號（學校＋校址），`PRI-`/`SEC-`/`SPE-`＋6位學校編號。上午、下午、全日班合併為一行。
- 同一學校編號的多個校址（臨時或分校舍）合併為一行。同一幼稚園的不同校舍，如果電郵相同就合併，`notes` 會註明「另有校舍」。
- 特殊學校的小學部及中學部合併為一行（`SPE`）。一條龍或同校的小學及中學部，電郵相同就合併為一行（`PRI`，註明「同校設小學及中學部」），電郵不同就分開兩行。
- 電郵會刪去 `mailto:`、轉成小寫並檢查格式。如果幾間學校共用同一個電郵，只保留在第一間（優先順序：小學、中學、特殊、幼稚園），其餘留空並在 `notes` 註明。
- `notes` 會標記「免費郵箱」、「可能為個人電郵」及「校長郵箱」，發送前請留意。
- 已停辦的學校不在教育局現行名單內。各概覽頁面都沒有出現「停辦」或「停止收生」等字眼。有一間只在 KGP 出現的幼稚園（港島蒙特梭利國際幼稚園）也已加入。

## 缺口

- 約一半幼稚園的概覽沒有電郵（填「-」），學校網站上也找不到。
- 國際、私立、夜校及大部分特殊學校不在概覽內，只能靠學校網站，所以覆蓋率較低。
- 中學資料用2025/26版，校長可能已經更換。

## 重新建立

原始下載會快取在 scratchpad 的 `schooldata/`（可以用環境變數 `SCHOOLDATA_DIR` 更改位置）。重跑時會讀快取，中斷後可以續跑。程式每秒最多發出2個請求。

```sh
python3 -I emails/scripts/data/scrape.py                # EDB + PSP + SSP + SPSP + KGP
python3 -I emails/scripts/data/build.py                 # 合併，並產生網站補漏清單
python3 -I emails/scripts/data/scrape.py web            # 學校網站補漏
python3 -I emails/scripts/data/build.py                 # 最終寫出 emails/data/schools.csv
```

要重新下載，刪除快取目錄 `schooldata/cache/` 即可。
